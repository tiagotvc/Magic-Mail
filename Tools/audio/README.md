# Trilha do mapa
- `compose-map-music-v3.cjs`: composicao (16 compassos x 2 voltas, 156 bpm) -> MIDI -> WAV com instrumentos sampleados.
  `node compose-map-music-v3.cjs <fluidsynth.exe> <GeneralUser-GS.sf2> Assets/RoyalAves/Resources/RoyalAvesMapMusic.wav`
- FluidSynth: https://github.com/FluidSynth/fluidsynth/releases | SoundFont: https://github.com/mrbumpy409/GeneralUser-GS (30 MB, nao versionado).
- `mapa-aventura.mid`: o MIDI da composicao (abra em qualquer DAW/MuseScore para editar).
- `compose-map-music.cjs` / `-v2.cjs`: versoes anteriores, sintese por codigo (soam como toque de celular).
