# Remodelagem dos seis elementos

Propostas visuais geradas com a ferramenta integrada ImageGen, usando cada arte atual e o escaninho aprovado como referencias.

- `familia-nova.png`: os seis novos visuais juntos.
- `antes-e-depois.png`: comparacao com as artes anteriores.
- `01-caixa.png` a `06-sinalizador.png`: originais gerados, transparentes, sem alteracao posterior.
- `prompts.json`: prompts completos, referencias, origem dos arquivos e hashes.

As pranchas apenas organizam as imagens para comparacao. Nao sao capturas do jogo. A bolsa atual na comparacao foi extraida do frame fechado existente; o tinteiro atual vem do primeiro estado da folha original.

Ainda nao instalados no jogo. Estados de dano, pecas separadas e animacoes precisam derivar do visual escolhido. Nenhum prefab, regra, fase ou asset de producao foi substituido.
